## FASTQ workflow

The `Makefile` downloads a subset of reads from an SRA accession and runs QC before and after trimming/filtering.

Default settings:

```make
ACC = SRR031127
N = 1000
SAMPLE = H_pylori_26695_$(ACC)
```

The default accession, `SRR031127`, is an Illumina single-end run for `Helicobacter pylori 26695`. The workflow uses only the first `N` reads, not the full dataset.

Run the workflow:

```bash
pixi run -m "$HOME/edu/bioinfo" make all
```

Use a different accession or read count:

```bash
pixi run -m "$HOME/edu/bioinfo" make all ACC=SRR031127 N=200
```

The workflow creates:

- `metadata/`: ENA run metadata
- `reads/raw/`: downloaded FASTQ subset
- `qc/raw/`: FastQC report for raw reads
- `reads/trimmed/`: fastp-filtered FASTQ
- `qc/trimmed/`: FastQC report for trimmed reads
- `reports/`: metadata summary and fastp reports
- `logs/`: download logs

The FASTQ files are renamed from the SRA accession to a more descriptive sample name, for example:

```text
H_pylori_26695_SRR031127.fastq
H_pylori_26695_SRR031127.trimmed.fastq
```

The Makefile uses `fastq-dump --split-3`, so paired-end accessions can also be handled by changing `ACC`.

## Validation run

I tested the workflow with a small subset:

```bash
pixi run -m "$HOME/edu/bioinfo" make -C week04 all N=200
```

The downloaded raw FASTQ contained:

```text
200 reads
15,200 bases
76 bp average read length
```

After `fastp`, the trimmed/filtered FASTQ contained:

```text
89 reads
6,764 bases
76 bp average read length
```

The `fastp` report showed:

- Reads before filtering: `200`
- Reads after filtering: `89`
- Reads failed due to too many `N` bases: `111`
- Reads failed due to low quality: `0`
- Adapter-trimmed reads: `0`

## Did QC make a difference?

Yes. In this small test subset, `fastp` made a clear difference by removing reads with too many `N` bases. It did not trim adapters, and the retained reads still had the same read length. The main effect was filtering problematic reads rather than shortening reads.

The visual QC reports to compare are:

- Raw reads: `qc/raw/H_pylori_26695_SRR031127_fastqc.html`
- Trimmed reads: `qc/trimmed/H_pylori_26695_SRR031127.trimmed_fastqc.html`

These reports are generated by the Makefile and are not committed to GitHub.
